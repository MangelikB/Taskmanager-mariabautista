Project Description – Workout Task Manager
This React-based SPA helps users plan and manage workout tasks by category (Cardio, Strength, Flexibility) and priority (High, Medium, Low). Users can add, search, filter, and mark tasks as completed. The app uses local storage to save data and features a responsive, user-friendly interface built with React, Vite, and custom CSS.
