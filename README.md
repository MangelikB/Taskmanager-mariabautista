This Project helps users plan and manage workout tasks by category (Cardio, Strength, Flexibility) and priority (High, Medium, Low). Users can create multiple custom workout lists, each with its own set of tasks. Within each list, users can add, search, filter, and mark tasks as completed. The app uses local storage to persist data across sessions and features a responsive, user-friendly interface built with React, Vite, and custom CSS.
